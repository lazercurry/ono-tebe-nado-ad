# Оно тебе надо! 💼

Проект разработан в рамках курса «Фронтенд-разработчик» от Яндекс Практикума.

##  Описание
Лендинг аукциона недвижимости с адаптивной версткой, сложной сеткой Grid Layout и интерактивными элементами. Проект демонстрирует навыки работы с современной CSS-версткой, позиционированием и семантической разметкой.

## 🛠 Технологии
*   **HTML5** (семантическая верстка)
*   **CSS3** (Flexbox, Grid Layout, позиционирование, анимации)
*   **JavaScript** (базовая логика взаимодействия)
*   **БЭМ** (методология именования классов)

##  Функционал
*   **Адаптивность:** Корректное отображение на мобильных устройствах, планшетах и десктопах.
*   **Grid Gallery:** Сложная сетка изображений с использованием `grid-template-areas` и `span`.
*   **Интерактивное меню:** Фиксированные пункты меню по углам экрана с всплывающими изображениями.
*   **Эффекты:** Плавные переходы, hover-эффекты на карточках и кнопках.
